NOTUN PRODUCT KIVABE ADD KORBE  (sohoj bhabe)
=============================================

Shob product ekta file-e thake:   assets/js/data/catalog.js
Website nijei oi file theke product dekhay. Design bodlate hoy na.

--------------------------------------------------------------
PODDHOTI 1 (shobcheye shohoj): shudhu chhobi rakho
--------------------------------------------------------------
Chhobi ekta folder-e rakho:

  FURNITURE
    assets/furniture/beds/         khat
    assets/furniture/sofas/        sofa
    assets/furniture/dining/       dining set
    assets/furniture/tables/       table
    assets/furniture/chairs/       chair
    assets/furniture/wardrobes/    wardrobe, almirah
    assets/furniture/showcases/    showcase
    assets/furniture/office/       office chair, study table
    assets/furniture/storage/      bedside, drawer

  HOME DECOR
    assets/home-decor/flower-pots/       fuler tob
    assets/home-decor/plants/            gach
    assets/home-decor/hanging-baskets/   jhulonto basket
    assets/home-decor/vases/             fuldani
    assets/home-decor/flowers/           sajano ful
    assets/home-decor/wall-decor/        dewal-er sajano
    assets/home-decor/table-decor/       table decor
    assets/home-decor/accessories/       accessories
    assets/home-decor/styling/           home styling

Chhobir naam = product-er naam:
    Royal Sofa Set.webp                    -> English naam
    Royal Sofa Set__রয়েল সোফা সেট.webp      -> English + Bangla naam (majhkhane duita underscore __)

Ek-i product-er aro chhobi dile naam-er pashe -2, -3 likho:
    royal-sofa-set.webp   (main)
    royal-sofa-set-2.webp (aro ekta angle)   -> product page-e gallery hoye jabe

GitHub-e upload korar 1-5 minute pore live site-e chhobi chole ashbe.

--------------------------------------------------------------
PODDHOTI 2: price, rong, maap, description shoho (recommended)
--------------------------------------------------------------
assets/js/data/catalog.js kholo. Ekta product-er block copy kore paste koro, tarpor
naam, chhobi, description, price, colors, dimensions bodle nao. Shob field-er byakkha
oi file-er shuru-te lekha ache.

  price: null      -> "Request a Quote" dekhabe
  price: 18500     -> "Tk 18,500" dekhabe

--------------------------------------------------------------
3D MODEL (.glb) pore dite chaile
--------------------------------------------------------------
GLB file assets/models/ folder-e rakho, tarpor oi product-er block-e likho:
    model: "assets/models/royal-sofa.glb",
    modelExact: true      (jodi model-ta ei product-er hubohu model hoy)
Model dile product page-e 3D viewer ashbe ar Virtual Showroom-er room-e boshbe.
Model na thakle shudhu real chhobi dekhay. Kono generic 3D ke real product bole dekhano hoy na.
